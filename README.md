# This is the data for my site

This is the source of my site running on http://frirasyidi.com. The site is
using [Astro](https://astro.build) to automatically stitch the data into a
static site on GitHub Pages, deployed via GitHub Actions on every push to
`master`.

## Running in local

1. **Install Node.js** (see `package.json`'s dependencies for the versions
   this was built against).
2. **Install dependencies**, go to the repository directory and run
   `npm install`.
3. **Run the dev server**: `npm run dev`; this will serve your site locally.
4. **Access it via [http://localhost:4321](http://localhost:4321)** from your
   browser.
